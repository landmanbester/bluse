# Track E implementation plan

**Spec:** [`../specs/2026-09-03-track-e-design.md`](../specs/2026-09-03-track-e-design.md)

**Goal:** ship a morphology-only RFI score for all 2,014,055 BLUSE hits, its
validation, and a pruned + ranked candidate list, by the end of the workshop.

**Architecture:** one new module `src/bluse/track_e_score.py` and one new
entry point `bluse-score`. It reads `features/all_features.parquet`, fits five
group-fold `HistGradientBoostingClassifier`s on the spatial filter's own
labels, and writes `scores/`. No new dependency. Everything else in the repo
is untouched except docs and the CLI table.

**Tech stack:** existing — numpy, pandas, pyarrow, scikit-learn ≥1.3,
matplotlib. `HistGradientBoostingClassifier` is the model; it handles NaN
natively, which matters because `x01_drift_residual` is NaN on 29.6% of rows
by construction.

## Global constraints

- **No new runtime dependency.** Not lightgbm, not shap, not xgboost.
- **Group split on `obsid`, always.** Never a random row split.
- **The default feature set is the 12 stamp-morphology columns**, from
  `F.all_columns(kind="stamp")` minus the two `_saturated` flags. Never
  hard-code the list — the registry is the source of truth.
- **`n_beams`, `n_beams_formed`, `beam_frac`, `flag_multibeam` are the label.**
  They must never enter a feature matrix. Assert it, do not just avoid it.
- **Positive-unlabelled framing in every user-facing string.** Low score is not
  evidence of a candidate; see spec §4.
- Reference numbers to reproduce: stamp OOF AUC **0.9891**, all-16 **0.9895**,
  Track A flags **0.9373**, non-zero-drift **0.9909**, SNR-decile-weighted
  **0.9243**, signal-level **0.9901**, singleton **0.9836**, survivors called
  RFI **2,708 / 4,565**.

    scored by a model that saw its observation."""

- [ ] **Step 7: write `fit_score`**

```python
def fit_score(df, *, features="stamp", n_splits=5, seed=0, exclude_mk=True,
              max_iter=300):
    """
    Fit group-fold models on the spatial filter's own labels and score everything.

    Returns (score, fold, info). `score` is P(n_beams >= 32 | features) -- an RFI
    PROXY, not a probability of RFI, and emphatically not a candidate ranking
    read backwards. See docs/superpowers/specs/2026-09-03-track-e-design.md #4.

    Labelled rows carry their out-of-fold score; unlabelled rows carry the mean
    of the n_splits fold models. `fold` is -1 for rows in no training fold.
    """
    cols = feature_columns(features)
    X = df[cols].to_numpy(np.float32)
    y = df["weak_label"].to_numpy()
    g = df["group_id"].to_numpy()
    train = y >= 0
    if exclude_mk and "file" in df:
        train &= (df["file"] != "mk_sample_hits").to_numpy()
    ...
```

Fold loop: `GroupKFold(n_splits).split(idx, y[train], g[train])`, fit on the
training part, write `score[test_rows]`, accumulate `predict_proba` on every
row outside `train` and divide by `n_splits` at the end. Record in `info`:
`features`, `columns`, `n_splits`, `seed`, `n_train`, `n_groups`, `base_rate`,
`exclude_mk`, `sklearn` version, and per-fold train/test sizes.

- [ ] **Step 8: run both tests, expect PASS**

- [ ] **Step 9: failing test — the score is reproducible and NaN-tolerant**

```python
def test_score_is_deterministic_and_survives_all_nan_column():
    """x01_drift_residual is NaN on 29.6% of real rows by construction (zero
    drift). HistGradientBoosting handles that natively -- pin it, because
    swapping in a model that does not would silently drop a third of the data."""
    df = fixtures.synthetic_weak_labelled(n=3000, groups=10, seed=1)
    df["x01_drift_residual_n"] = np.nan
    a, _, _ = track_e_score.fit_score(df, features="all", n_splits=3, seed=7)
    b, _, _ = track_e_score.fit_score(df, features="all", n_splits=3, seed=7)
    assert np.array_equal(a, b) and np.isfinite(a).all()
```

### Task 4 — the candidate list and the disagreement catalogue

**Files:** modify `src/bluse/track_e_score.py`; `tests/unit/test_track_e_cli.py`

The scientific product. Three populations, each written with a one-line reason:

- [ ] **Step 1: `PRUNED`** — survivors with `rfi_score > 0.9`. 2,708 hits the
      spatial filter passed and morphology rejects. **The actionable output.**
- [ ] **Step 2: `SHORTLIST`** — survivors with `rfi_score < 0.1`, ranked. 618.
      Labelled in the file itself with spec §4's warning, so a low score cannot
      be quoted as a candidate without the caveat travelling with it.
- [ ] **Step 3: `CONTRARIAN`** — `n_beams >= 32` and `rfi_score < 0.1`. The
      spatial filter says RFI, morphology disagrees. Instrumental artefacts, or
      the model's blind spot. Either way it is the set that teaches us most.
- [ ] **Step 4: cross-tab the score against the Track B families** on
      `lband_short` — `taxonomy.name_families` already gives the family table.
      A named family that scores clean is either a mis-named family or a real
      finding. Cheap, and it connects the two tracks.
